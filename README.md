# X-Files

**Design meets engineering.**

X-Files is a collaborative website project for a technology and creative services brand. The site introduces the team's approach to product design, software development, and digital solutions through a bold, responsive interface.

## Overview

The website is organized around the brand's services, selected work, process, capabilities, and contact information. Its visual direction combines strong typography, dark backgrounds, and motion to create a distinct identity.

## Built with

- **React** for the interface and component structure
- **JavaScript (JSX)** for application behavior
- **CSS** for layout, styling, responsive behavior, and visual effects
- **Vite** for development and production builds
- **ESLint** for code linting

## Features

- Responsive, section-based landing page
- Navigation that changes appearance on scroll
- Active navigation states based on the section in view
- Animated visual styling and transitions
- Sections for services, selected projects, process, capabilities, and contact
- Reusable scroll-reveal component using the Intersection Observer API (included in the source)

> **Project status:** The website has been deployed. The selected-work section currently uses sample project entries; these should not be interpreted as completed client projects.

## Run locally

**Requirements:** Node.js and npm.

```bash
git clone https://github.com/Xcel27/X-Files.git
cd X-Files
npm install
npm run dev
```

Open the local URL printed by Vite.

## Available commands

```bash
npm run dev      # Start the development server
npm run build    # Create a production build
npm run preview  # Preview the production build
npm run lint     # Run ESLint
```
